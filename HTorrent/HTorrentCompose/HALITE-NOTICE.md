# Halite toolbar artwork

`src/main/resources/halite-toolbar.bmp` is the original `res/Toolbar2k.bmp` from
[Halite](https://github.com/Eoinocal/Halite), by Eóin O'Callaghan and contributors.
It is used for HTorrent's toolbar icons. The Halite source distribution includes
the Boost Software License 1.0, reproduced in `licenses/Halite-LICENSE.txt`.

Halite's readme credits nudone (Nick Pearson) for its application icon. HTorrent
retains its own application icon and uses only Halite's toolbar strip.
