HTORRENT FOR ANDROID: LICENSES AND SOURCE CODE

HTorrent for Android is a rebranded copy of the Android app from Nexonic Download
Manager by Shahrukh Khalid (https://github.com/Shahrukhalid/nexonic-download-manager).

The Android app as a whole (the APK) is distributed under the GNU General Public
License, version 3 (GPL-3.0), because it includes the video engine below, which is
licensed under GPL-3.0. The full text is in GPL-3.0.txt.

Nexonic's own source code (by Shahrukh Khalid) is also available separately under
MIT OR Apache-2.0, at your option (MIT-Nexonic.txt, Apache-2.0.txt). Both licenses
are compatible with GPL-3.0. Nothing in the app's terms of use limits the rights the
GPL-3.0 and the other licenses below give you.

SOURCE CODE (Corresponding Source)
- HTorrent for Android, exactly as built for each release: the matching version
  tag at https://github.com/skonester/HTorrent (build steps: android/README.md). The source archive is also attached to every GitHub release.
- Every release also has Android-GPL-Sources.tar.gz attached: the source of
  youtubedl-android 0.18.1 (https://github.com/yausername/youtubedl-android),
  the Termux recipes and patches used to build its Python and FFmpeg
  (https://github.com/termux/termux-packages), and the original source archive
  of every library they are built with.
If you cannot get any of this source, ask at
https://github.com/skonester/HTorrent/issues and it will be
provided free of charge for at least three years after the last release that
included it.
